# Create Conflicting Branches and Resolve Manually

## Task Brief
Build two feature branches with overlapping changes, trigger a merge conflict, resolve it manually, and document the resolution process in your portfolio repo wiki.

## Scenario
Your team is working on parallel features. Two branches modify the same file. You must resolve the conflict and document the strategy.

## Deliverables
- Merged pull request with resolved conflict
- Wiki page documenting conflict resolution strategy

## Success Criteria
- Conflict resolved without losing either branch logic
- PR merged to main with clear commit messages
